# Worker Selection App

Подбор промышленных рабочих с проверкой навыков по интервью и прогнозом удержания на 90 дней. Система проводит интервью с кандидатом, извлекает навыки и предпочтения с помощью LLM, подтверждает каждый навык дословной цитатой из ответов и ранжирует кандидатов по двум осям: техническое соответствие и бытовой комфорт.

Всё работает локально: LLM через Ollama, распознавание речи через faster-whisper, без внешних API.

![Шорт-лист вакансии](docs/shortlist.png)

## Возможности

- **Интервью по сценарию вакансии.** Вопрос на каждый обязательный навык, удостоверения, график, дорога, зарплата, бытовые условия, формат работы, смены мест работы. Вопросы озвучиваются голосом браузера.
- **Загрузка готового интервью.** Текстовая расшифровка (`.txt`, `.md`) или аудио (`.wav`, `.mp3`, `.m4a`, `.ogg`, `.webm`, `.flac`, `.aiff`) до 25 МБ.
- **Проверка навыков по цитатам.** LLM выбирает навыки только из справочника и приводит цитату. Навык засчитывается, если цитата действительно есть в репликах кандидата и относится к этому навыку.
- **Две оси соответствия.** "Навыки" - стаж, разряд, допуски, аттестации. "Комфорт" - график, дорога, зарплата, бытовые условия, работа в бригаде или в одиночку.
- **Прогноз удержания.** CatBoost с монотонными ограничениями оценивает вероятность проработать 90 дней, SHAP показывает вклад каждого фактора в процентных пунктах.
- **Шорт-лист.** 5 лучших кандидатов из прошедших проверку навыков. Итог = 40% навыки + 25% комфорт + 35% удержание.

![Отчёт по кандидату](docs/report.png)

## Как это устроено

```
интервью / расшифровка / аудио
        │
        ├─ faster-whisper ──> текст
        │
        ├─ Ollama (qwen3.5:9b, JSON-схема) ──> профиль кандидата
        │
        ├─ сверка цитат с репликами кандидата ──> подтверждённые навыки
        │
        └─ matching + CatBoost ──> навыки, комфорт, удержание ──> шорт-лист
```

| Слой | Технологии |
|---|---|
| Backend | Python 3.11, FastAPI, SQLModel, SQLite |
| LLM | Ollama, `qwen3.5:9b` с ответом по JSON-схеме |
| Распознавание речи | faster-whisper `large-v3-turbo`, CPU, int8 |
| Модель удержания | CatBoost, SHAP |
| Frontend | HTML, CSS, JavaScript без сборки |

Демо-данные: машиностроение, три профессии (оператор ЧПУ, сварщик, электромеханик), 6 вакансий и 48 синтетических кандидатов. Модель удержания обучается при первом запуске на синтетической выборке из 6000 пар "кандидат - вакансия" (ROC-AUC около 0.80) и сохраняется в `data/`.

## Запуск

Требования: [uv](https://docs.astral.sh/uv/), [Ollama](https://ollama.com). Проверено на Apple M1 Pro 16 ГБ.

```bash
make setup   # зависимости, qwen3.5:9b (~6.6 ГБ), модель faster-whisper (~1.6 ГБ)
make run     # http://127.0.0.1:8000
```

Без `make`:

```bash
uv sync
ollama pull qwen3.5:9b
uv run uvicorn main:app --host 127.0.0.1 --port 8000
```

Для проверки загрузки есть примеры интервью в `examples/`, включая аудиозапись `candidate1_audio.m4a`. Разбор одного интервью на M1 Pro занимает около 40 секунд.

### Docker

LLM остаётся на хосте, контейнер обращается к ней через `host.docker.internal`.

```bash
make docker-build
docker run -p 8000:8000 worker-selection-app
```

## Настройка

Параметры задаются переменными окружения или файлом `.env`, пример - `.env.example`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LLM_BASE_URL` | `http://127.0.0.1:11434` | адрес Ollama |
| `LLM_MODEL` | `qwen3.5:9b` | модель в Ollama |
| `LLM_TIMEOUT` | `300` | таймаут запроса к LLM, с |
| `STT_MODEL` | `large-v3-turbo` | модель faster-whisper |
| `DATA_DIR` | `data` | база и обученная модель удержания |
| `DATABASE_URL` | SQLite в `DATA_DIR` | строка подключения к БД |

`make reset` удаляет базу и модель удержания, при следующем запуске они создаются заново.

## Ограничения

- Данные о кандидатах и исходах найма синтетические, прогноз удержания демонстрирует подход, а не реальную статистику.
- Интервью текстовое: вопросы звучат голосом браузера, ответы вводятся текстом. Аудио принимается только готовым файлом.
- Вакансии заданы демо-набором в `app/services/demo_data.py`.
