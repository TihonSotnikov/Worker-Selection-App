# План развития

## Что входит в MVP (сделано)

Закрыты обязательные компоненты ТЗ ([описание_задачи.md](./описание_задачи.md)):

| Требование ТЗ | Как сделано |
|---|---|
| Голосовое интервью (в симуляции — текст с пометкой «голос») | Чат-интервью по сценарию вакансии, вопросы озвучиваются голосом браузера. Можно загрузить готовую расшифровку или аудио (faster-whisper) |
| Проверка ≥ 2 профессиональных навыков | На каждый обязательный навык свой вопрос. LLM извлекает стаж и дословную цитату, навык засчитывается, только если цитата есть в ответах кандидата |
| Сбор 3+ «мягких» критериев | График, дорога, зарплата, бытовые условия (столовая, душ, общежитие, развозка), бригада или работа в одиночку, смены работы |
| Ранжирование по двум осям + прогноз удержания | Ось «Навыки» и ось «Комфорт» + CatBoost-прогноз удержания на 90 дней с SHAP-объяснением. Шорт-лист из 5 кандидатов |
| Одна отрасль, синтетические данные | Машиностроение: оператор ЧПУ, сварщик, электромеханик. 6 вакансий, 48 синтетических кандидатов |
